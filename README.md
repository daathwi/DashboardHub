# Business Dashboards - Professional Dashboard System

A comprehensive, fully responsive business dashboard system with 7 interactive dashboards. Built with modern web technologies to showcase professional frontend development skills.

## 🚀 Live Demo

**[Deploy to Vercel/Netlify to get your live URL]**

## ✨ Features

### 7 Complete Dashboards
- **Sales Dashboard** - Revenue tracking, order analytics, product performance
- **Manager Dashboard** - Team performance, KPI tracking, productivity metrics
- **Customer Tracking** - Customer database, engagement metrics, LTV analysis
- **Drafts Dashboard** - Document management, workflow tracking, status distribution
- **Analytics Dashboard** - User analytics, conversion tracking, traffic sources
- **Finance Dashboard** - Financial overview, cash flow, expense tracking
- **Marketing Dashboard** - Campaign performance, lead generation, ROI analysis

### 🎨 Key Features
- ✅ **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- ✅ **Interactive Charts** - Beautiful data visualizations using Recharts
- ✅ **Real-time Simulation** - Dynamic data updates with refresh functionality
- ✅ **Modern UI/UX** - Clean, professional design with Tailwind CSS
- ✅ **Fast Performance** - Built with Vite for optimal loading speeds
- ✅ **Mobile Menu** - Hamburger menu for mobile navigation
- ✅ **Professional Layout** - Fixed sidebar with smooth transitions

## 🛠️ Technology Stack

- **React 18** - Modern UI framework
- **Vite** - Lightning-fast build tool
- **React Router** - Client-side routing
- **Tailwind CSS** - Utility-first styling
- **Recharts** - Professional chart library
- **Lucide React** - Beautiful icon set

## 🚀 Quick Start

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Visit `http://localhost:5173`

### Production Build
```bash
npm run build
npm run preview
```

## 📦 Deployment

### Deploy to Vercel (Recommended)
```bash
npm install -g vercel
npm run build
vercel
```

### Deploy to Netlify
1. Push code to GitHub
2. Connect repo to Netlify
3. Build command: `npm run build`
4. Publish directory: `dist`
